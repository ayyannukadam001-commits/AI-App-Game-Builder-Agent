# AI App & Game Builder Agent

A mobile-first AI-assisted workspace for planning app and game projects. This repository is the source of truth; no Floot dependency.

## Current milestone

- Responsive Builder dashboard and project brief form.
- Ten specialist roles coordinated in a sequential planning workflow.
- FreeLLMAPI integration through its OpenAI-compatible `/v1/models` and `/v1/chat/completions` endpoints.
- Server-side API key handling; secrets are not exposed to the browser.
- GitHub Actions web build and syntax-check workflow.
- Honest capability states: local/offline inference and native APK compilation are not implemented yet.

## Requirements

- Node.js 20+
- A running FreeLLMAPI instance and its unified API key for AI planning.

## Run locally

```bash
npm install
cp .env.example .env
```

Set `FREELLMAPI_BASE_URL` and `FREELLMAPI_API_KEY` in `.env`, then:

```bash
npm run dev
```

Open the Vite URL printed in the terminal. The API server runs on port 8787.

For production, build the frontend and start the server:

```bash
npm run build
npm start
```

## FreeLLMAPI configuration

- `FREELLMAPI_BASE_URL`: base URL of your own FreeLLMAPI server (for example `http://127.0.0.1:3001`).
- `FREELLMAPI_API_KEY`: unified API key generated by your FreeLLMAPI instance.
- `FREELLMAPI_MODEL`: optional exact model ID from `/v1/models`.

The app fetches models from `/v1/models` and sends agent requests to `/v1/chat/completions`. The server keeps the key private. Provider/model free-tier availability and quotas are controlled by upstream providers and may change.

## Agent workflow

Manager, Planner, Architect, UI/UX, Frontend, Backend, Database, Game, Tester/Debugger and Build/Release roles run sequentially and share prior findings. They currently generate a plan; they do not autonomously edit arbitrary files or run external build tools yet.

## Not implemented yet

- Local/offline model runtime.
- Autonomous code-writing agent with isolated workspace and approval gates.
- Native Android APK build pipeline and verified APK artifacts.
- Deployment, account system, database-backed project history and cloud hosting.

These are intentionally marked unavailable until real implementations and tests exist. FreeLLMAPI is an inference gateway, not an Android compiler.
